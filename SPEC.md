# nnls-tutorial: specification

A series of Jupyter notebooks teaching how non-negative least squares (NNLS) works: its geometry,
its optimality conditions, the classic active-set algorithm, the numerical linear algebra behind
a fast solver, and the "try every support" method that MrFitty's
`notebooks/blocked_cross_validation.ipynb` (Appendix A) uses for many small fits.

Established by interview, 2026-10-19.

## Notation

Used everywhere: notebooks, figures and package code.

| Symbol | Meaning |
|---|---|
| $R = [r_1 \cdots r_m]$ | the matrix of reference spectra, one column $r_i$ per reference |
| $s$ | the measured (unknown) spectrum |
| $w = (w_1, \dots, w_m)$ | the weights; $\hat w$ least squares, $w^\*$ NNLS |
| $e = s - Rw$ | the residual (error) |
| $p = R\hat w$, $q = Rw^\*$ | the projections onto the span and onto the cone |
| $i$ | column (reference) index |

## 1. Audience and voice

- **Reader:** an undergraduate math major who has taken **one linear algebra course** (span,
  rank, orthogonality, projections, determinants, eigenvalues as a definition). Nothing beyond
  that is assumed. Everything else is built up in the notebooks, gently, when it is first
  needed: gradients of quadratic functions, convexity, KKT conditions, the spectral theorem for
  symmetric matrices (stated, used), Rayleigh quotients, floating point and condition numbers.
- **Rigor:** state the key claims as results and **prove them**, with short proofs placed next
  to the picture that motivates each one. Key claims:
  1. Least squares is orthogonal projection, and the normal equations characterize it.
  2. NNLS is projection onto the convex cone generated by the columns. A solution exists, and the
     fitted vector $Rw^\*$ is unique.
  3. KKT conditions for NNLS: necessary and sufficient (convexity).
  4. Support enumeration is exact: the best feasible candidate over all $2^m-1$ supports, plus
     $x=0$, is an NNLS solution.
  5. Singular supports can be skipped (some optimal solution has linearly independent support
     columns).
  6. $\kappa(R^\top R)=\kappa(R)^2$.
  7. Principal submatrices are no worse conditioned: via Rayleigh quotients (the extreme case
     of Cauchy interlacing, which is all that is needed).
  8. $\kappa(G)\le \operatorname{tr}(G)\operatorname{tr}(G^{-1})\le m^2\kappa(G)$, and
     $\operatorname{tr}(G^{-1})=\|L^{-1}\|_F^2$ when $G=LL^\top$.
  9. The error identity $\|A_Pz-y\|^2 = y^\top y - z^\top c_P$ when $G_{PP}z=c_P$.
  10. Lawson–Hanson terminates (sketch: the objective strictly decreases and supports don't repeat).
- **Voice:** conversational and informal. Asides, intuition first, "here's the catch"
  moments, but always with concrete numbers. Math in LaTeX (`$\|Rw-s\|^2$`), not Unicode.
- **Exercises:** 2–4 per notebook (prove a small lemma, predict a picture before revealing
  it, break an algorithm), with solutions in collapsed `<details>` blocks.

## 2. Framing

Math first, with XANES as the motivation. Notebook 1 opens with the real problem: a measured
arsenic spectrum is a mix of reference spectra, and the mixing fractions can't be negative.
Unconstrained least squares hands back a negative weight, which is physically meaningless.
The mathematics is then developed on small synthetic examples in $\mathbb{R}^2$/$\mathbb{R}^3$,
where everything can be drawn, and the series returns to real spectra at the end (notebooks 4–5).

## 3. Notebook series

Each notebook is short and focused and imports shared code from the `nnls_tutorial` package.

## 4. Interactivity

- **ipywidgets** (sliders and dropdowns) driving matplotlib redraws through
  `ipywidgets.interactive`/`interactive_output`, with inline backend redraw. No ipympl unless
  smoothness demands it.
- **Static fallback for every widget:** each interactive cell also emits a static figure, either
  a snapshot or a small-multiples grid at representative slider values, so the rendered
  notebooks read fully on GitHub, on nbviewer or as HTML without a kernel. Pattern: each widget
  helper in `nnls_tutorial.spectrum_space`, `nnls_tutorial.weight_space` and
  `nnls_tutorial.active_set_walk` has a matching `*_static()` that the cell calls first.
- **Front end:** JupyterLab (`uv run jupyter lab`).

## 5. Code: the `nnls_tutorial` package

Teaching implementations re-derived from scratch: clear, commented, **no dependency on
mr-fitty**. All are tested against `scipy.optimize.nnls`.

```
src/nnls_tutorial/
  data.py          load bundled .e spectra, interpolate references onto the unknown's energies
  solvers.py       lstsq_normal, cholesky, forward/back substitution, nnls_enumerate,
                   nnls_active_set (returns an iteration history for plotting),
                   batched_cholesky_solve, batched_nnls, numba kernel (refit_one)
  conditioning.py  cond via eigvalsh, trace bound, digits-lost experiments
  geometry.py      cone/span projections, support-region computation in R^2/R^3
  plotting.py      shared figure helpers (cones, contours, candidate markers), one style
  spectrum_space.py  notebook 1's figures (spectrum space): widgets + *_static fallbacks
  weight_space.py    notebook 2's figures (weight space): widgets + *_static fallbacks
  active_set_walk.py notebook 3's figures (the walk in both spaces, costs): widgets + *_static
```

## 8. Acceptance criteria

- `uv sync && make test` passes from a fresh clone. Every notebook executes top to bottom.
- Every solver agrees with `scipy.optimize.nnls`: weights within 1e-9 on well-conditioned random
  problems, and fit error within 1e-12 including duplicate columns.
- Every widget has a static fallback visible in `rendered/`.
- Each notebook has 2–4 exercises with collapsed solutions.
- All ten key claims in §1 are stated and proved somewhere in the series.
